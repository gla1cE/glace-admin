i Grand final reset (double final) The winners-bracket champion reaches the grand final with zero losses; the losers-bracket champion arrives with one. For a fair finish, the LB team must beat the WB team twice. Example: WB champ "Team A" meets LB champ "Team B". If B wins game 1, both now have one loss, so a second deciding game is played. If A wins game 1, A is champion immediately \u2014 B already had its one loss. Turn this off for a single grand final: one game decides it, and the LB champion gets no second chance.
